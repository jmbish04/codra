# Jules Session Dedup & Ledger Foundation (P0 + P3) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the `jules_sessions` ledger columns (`category`, `kind`, `target_files`, `automation_mode`) and stop the runaway duplicate docs sessions by folding a new docs task into an already-running one instead of launching a second.

**Architecture:** A D1 migration adds the columns; `stageJulesSession` stamps them at review time. At PR-merge launch time, a new `foldIntoOutstandingDocsSession` guard checks D1 for an `INTERNAL_CODRA` docs session that is still running (launched, no PR yet) and, if found, sends the new task to it via `sendJulesLogged` rather than opening a new session. D1 is the source of truth — no Jules SDK enumeration, no blocking loops.

**Tech Stack:** TypeScript, Cloudflare Workers, Hono, Drizzle ORM + D1, drizzle-kit migrations, vitest with an in-memory `node:sqlite` D1 shim.

## Global Constraints

- No raw SQL. Schema changes go in Drizzle schema files; migrations are produced by `npm run db:generate` and applied with `npm run migrate:local` (local/preview) then `npm run migrate` (remote). There is **no** `migrate:db` script.
- Migrations output dir: `db/migrations/d1`. Latest existing: `0028_loud_puff_adder.sql`; this plan produces `0029_*`.
- Tests use `createTestEnv()` from `test/helpers.ts`, which builds a fresh in-memory D1 with all `db/migrations/d1/*.sql` applied in `beforeEach`. Statement delimiter in migration files is `--> statement-breakpoint`.
- `category` enum values: `'INTERNAL_CODRA' | 'EXTERNAL_MANUAL' | 'EXTERNAL_CI'`. Codra-staged docs sessions are always `INTERNAL_CODRA`, `kind = 'docs'`.
- The launch path (`launchStagedJulesSessions`) is best-effort and must never throw — preserve that.
- Dependency injection follows the existing `Deps` pattern in `core/jules.ts` (inject side-effecting collaborators so units are testable without network).

**Deferred (not in this slice):** persisting inbound Jules replies (`direction:'inbound'`) from the poller. It's independent of dedup, and the poller's file path needs on-the-ground confirmation. It lands in the P1+P2 plan.

```ts
/**
 * The one INTERNAL_CODRA docs session that is still running for this repo
 * (launched, has a session_id, hasn't opened a PR yet). Used to fold a new docs
 * task into an existing session instead of launching a duplicate.
 */
export async function findOutstandingCodraDocsSession(
  env: Pick<Env, 'DB'>, q: { owner: string; repo: string },
): Promise<JulesSessionRow | null> {
  const db = getDb(env);
  const row = await db.select().from(julesSessions)
    .where(and(
      eq(julesSessions.owner, q.owner),
      eq(julesSessions.repo, q.repo),
      eq(julesSessions.category, 'INTERNAL_CODRA'),
      eq(julesSessions.kind, 'docs'),
      eq(julesSessions.state, 'launched'),
      isNotNull(julesSessions.session_id),
      isNull(julesSessions.created_pr_number),
    ))
    .orderBy(desc(julesSessions.created_at))
    .limit(1)
    .get();
  return row ?? null;
}
```

- [ ] **Step 4: Implement the helper**

In `src/server/core/jules.ts`, after the `MergeGithub` type (ends line 15) and before `launchStagedJulesSessions` (line 17), add:

```ts
/**
 * If an INTERNAL_CODRA docs session is still running for this repo (launched, no
 * PR yet), send the new task to it and mark this staged row skipped, instead of
 * opening a second session. Returns true when folded (caller must skip launch).
 * `send` is injectable so the decision + logging are testable without network.
 */
export async function foldIntoOutstandingDocsSession(
  env: Env, apiKey: string, github: MergeGithub,
  ctx: { owner: string; repo: string; prNumber: number }, row: JulesSessionRow,
  send: typeof sendJulesLogged = sendJulesLogged,
): Promise<boolean> {
  const outstanding = await findOutstandingCodraDocsSession(env, { owner: ctx.owner, repo: ctx.repo });
  if (!outstanding?.session_id) return false;

  await send(env, apiKey, {
    sessionId: outstanding.session_id, kind: 'improve', text: row.prompt,
    repository: `${ctx.owner}/${ctx.repo}`, prNumber: ctx.prNumber,
  });
  await markJulesOutcome(env, row.id, {
    state: 'skipped', errorMsg: `Folded into outstanding session ${outstanding.session_id}`,
  }).catch(() => {});

  const body = `📚 An existing Jules docs session is still running, so Codra sent these documentation gaps to it instead of opening a new one.\n\n- Session: ${outstanding.session_url ?? outstanding.session_id}`;
  if (row.pr_comment_id != null) await github.updateIssueComment(ctx.owner, ctx.repo, row.pr_comment_id, body).catch(() => {});
  else await github.createIssueComment(ctx.owner, ctx.repo, ctx.prNumber, body).catch(() => {});

  return true;
}
```
